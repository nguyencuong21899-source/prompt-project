# Sao lưu prompt Của tôi

Từ bản 0.8.6, mở Prompt → Của tôi:

- **Xuất file:** tải toàn bộ prompt cá nhân thành file `prompt-cnc-ca-nhan-YYYY-MM-DD.json`. Bộ lọc đang chọn không giới hạn những prompt được xuất.
- **Nhập file:** chọn file sao lưu đó trên máy hoặc bản cài mới. Prompt đang có được giữ nguyên. Bản trùng hoàn toàn được bỏ qua; prompt cùng tên nhưng khác nội dung được thêm thành bản riêng.

Không cần mật khẩu quản lý; file không gửi lên máy chủ. Mỗi file tối đa 5 MB, 500 prompt. Nếu có nội dung không hợp lệ, file bị từ chối trước khi lưu. Không nhập danh sách prompt Công ty bằng chức năng này.

File chứa tên, mô tả, danh mục và nội dung; không chứa yêu thích, lịch sử dùng, mật khẩu quản lý hay ID của bản cài cũ. Nội dung không được mã hóa; hãy giữ file ở nơi phù hợp và kiểm tra việc khôi phục trước khi gỡ bản cài cũ.

Khi chuyển sang bản Store: xuất trên bản cài cũ → cài bản mới có chức năng nhập → mở Của tôi → Nhập file → kiểm tra prompt rồi mới gỡ bản cũ.
